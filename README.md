## AI Text Generator
A simple web-based text generation application built with Streamlit and Hugging Face Transformers. The app allows a user to enter a sentence or short prompt and generates a continuation using a pretrained language model.

## About the Project
This project demonstrates how a pretrained Transformer model can be connected to a simple interactive interface.

The application uses the Qwen2.5-0.5B-Instruct model from Hugging Face instead of training a language model from scratch. Streamlit is used to provide the user interface.

## Features
- Simple text input
- AI-generated text completion
- Loading message while generating
- Customized Streamlit interface
- Coral-themed background
- Separate output section
- Pretrained Transformer model
- Model caching for faster interaction

## Technologies Used
- Python
- Streamlit
- Hugging Face Transformers
- PyTorch
- Qwen2.5-0.5B-Instruct
## How It Works
User enters a prompt
        ↓
Streamlit receives the input
        ↓
Qwen Transformer model processes the prompt
        ↓
Model generates additional text
        ↓
Generated text is displayed
## Model
The application uses:

Qwen/Qwen2.5-0.5B-Instruct
The model is loaded using the Hugging Face Transformers pipeline:

from transformers import pipeline

generator = pipeline(
    "text-generation",
    model="Qwen/Qwen2.5-0.5B-Instruct"
)
## Installation
Make sure Python is installed on your system.

Install the required packages:

pip install streamlit transformers torch
## Running the Application
Save the Python program as:

text\_generator.py
Open a terminal in the project folder and run:

streamlit run text\_generator.py
The application will normally open at:

http://localhost:8501
## Example
Enter a prompt such as:

Artificial Intelligence is
The model will generate text based on the prompt.

The output may be different for different runs because it is generated by a language model.
